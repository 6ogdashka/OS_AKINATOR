# Бой Акинаторов (Akinator Battle)

Онлайн-дуэль «угадай персонажа» на двоих: авторитетный TCP-сервер на Linux и два
GUI-клиента на Qt Widgets (C++17). В наборе 60 персонажей и 139 вопросов. Ответ на
вопрос считает **только сервер** — по таблице признаков загаданного персонажа,
поэтому клиент не может «подсмотреть» ответ.

```
[ Windows: клиент ]───┐
                      ├── сеть ZeroTier ──▶ [ Linux: сервер :9999 ]
[ Linux: клиент ]─────┘
```

Гайд линейный: **часть 1** — сервер на Linux, **часть 2** — клиент на Windows,
**часть 3** — правила игры. Если оба клиента на одной машине, в поле адреса
достаточно `127.0.0.1`.

## Что понадобится

| Машина | Что установить |
|---|---|
| Linux (хостит сервер) | Qt 6.5+ (Core, Network, Widgets, Test), CMake ≥ 3.16, компилятор C++17, ZeroTier |
| Windows (клиент) | Qt 6.5+ через Qt Online Installer (Qt Creator + комплект MSVC или MinGW); для MSVC — Visual Studio Build Tools |

## Часть 1. Linux: сервер и ZeroTier

### 1.1. Зависимости

```bash
# Debian / Ubuntu
sudo apt update
sudo apt install -y build-essential cmake qt6-base-dev qt6-base-dev-tools
```

```bash
# Fedora
sudo dnf install -y gcc-c++ cmake qt6-qtbase-devel
# Arch
sudo pacman -S --needed base-devel cmake qt6-base
```

### 1.2. Сборка

```bash
cd <путь к репозиторию>
cmake -S . -B build
cmake --build build -j"$(nproc)"
```

Всё складывается в `build/bin`: `akinator-server`, `akinator-client`,
`tst_gamecore`, `tst_protocol`, `libgamecore.so`. Тесты (необязательно):

```bash
ctest --test-dir build --output-on-failure
```

### 1.3. ZeroTier: подключить машину к сети

```bash
curl -s https://install.zerotier.com | sudo bash   # установка
sudo zerotier-cli join <NETWORK_ID>                # ID сети из my.zerotier.com
```

Затем на https://my.zerotier.com открыть нужную сеть и поставить **галочку Auth**
у появившегося участника — без авторизации соединения не будет. Когда сеть
поднялась, статус будет `OK`:

```bash
sudo zerotier-cli listnetworks
# 200 listnetworks <id> <name> <mac> OK PRIVATE ztfcarbqgh 10.126.245.249/24
```

Здесь `ztfcarbqgh` — имя виртуального интерфейса, `10.126.245.249/24` — адрес
машины в ZeroTier.

### 1.4. Получить адрес для подключения

Это и есть адрес, который вводят клиенты (шаг 2.5):

```bash
ip -4 -o addr show | awk '/ zt/ {split($4, a, "/"); print a[1]; exit}'
# 10.126.245.249
```

Если адрес удобнее взять прямо из ZeroTier, посмотреть полную строку сети:

```bash
sudo zerotier-cli listnetworks
# 200 listnetworks <id> <имя_сети> <mac> OK PRIVATE ztfcarbqgh 10.126.245.249/24
```

или сразу вывести только адрес:

```bash
sudo zerotier-cli listnetworks | tr ' ' '\n' | grep -m1 -E '^[0-9]+(\.[0-9]+){3}/' | cut -d/ -f1
```

Адрес назначается сетью и переживает перезагрузку; проверить его повторно можно
любой из команд выше.

### 1.5. Запустить сервер

```bash
GAME_SERVER_PORT=9999 ./build/bin/akinator-server
```

В логе появится `Сервер слушает 0.0.0.0:9999`. Сервер слушает все интерфейсы,
включая `zt*`, поэтому под ZeroTier отдельно настраивать ничего не нужно. Порт
можно не указывать — по умолчанию `9999`.

### 1.6. Проверить, что порт открыт

```bash
ss -ltn | grep 9999        # ожидается *:9999
```

Если на Linux включён фаервол — разрешить порт:

```bash
sudo ufw allow 9999/tcp                      # Debian / Ubuntu
sudo firewall-cmd --add-port=9999/tcp        # Fedora
```

## Часть 2. Windows: клиент

### 2.1. Скачать и установить Qt

1. Открыть https://www.qt.io/download-qt-installer и скачать **Qt Online
   Installer** (нужен бесплатный аккаунт Qt).
2. Запустить установщик, войти. На шаге выбора папки запомнить путь установки —
   дальше он обозначается как `<папка Qt>`: **у каждого он свой**, по умолчанию
   что-то вроде `C:\Qt`.
3. `Qt` → `Qt 6.x` → отметить **один** комплект:
   - **MSVC 2022 64-bit** — если на машине есть (или будет) Visual Studio;
   - **MinGW 64-bit** — если Visual Studio ставить не хочется, компилятор идёт в комплекте.
4. В `Developer and Designer Tools` оставить отмеченными **Qt Creator**,
   **CMake**, **Ninja** (обычно отмечены по умолчанию).
5. Дождаться установки. Qt Test, Network и Widgets входят в выбранный комплект —
   отдельно ничего доставлять не нужно.

Если выбран комплект MSVC, компилятор ставится отдельно:
https://visualstudio.microsoft.com/downloads → **Build Tools for Visual Studio** →
workload **Desktop development with C++**.

### 2.2. Собрать в Qt Creator (ничего настраивать не нужно)

1. `Qt Creator` → `File` → `Open File or Project…` → выбрать `CMakeLists.txt` в
   корне репозитория.
2. В окне `Configure Project` отметить комплект из шага 2.1
   (`Desktop Qt 6.x MSVC2022 64-bit` или `Desktop Qt 6.x MinGW 64-bit`).
3. `Build` → `Build Project` (`Ctrl+B`), затем `Run` (`Ctrl+R`) — клиент
   запустится сразу, путь к Qt Creator подставляет сам.
4. Готовый файл лежит в папке сборки: `<папка сборки>\bin\akinator-client.exe`.
   Текущий путь виден в `Projects` → `Build` → `Build directory`; если хотите,
   чтобы он совпадал с гайдом, впишите туда `<путь к репозиторию>\build`.

### 2.3. Вариант без Qt Creator (консоль)

Нужен путь к **папке Qt-комплекта** — это каталог, внутри которого есть
`bin\qmake.exe` и `lib\cmake\Qt6` (по форме: `<папка Qt>\6.x.y\msvc2022_64`).
Как узнать точно, не угадывая:

- в Qt Creator: `Edit` → `Preferences…` → `Kits` → `Qt Versions` — там полный путь
  к `qmake.exe`, папка комплекта на два уровня выше;
- или в проводнике: `<папка Qt>` → `6.x.y` → `msvc2022_64` (либо `mingw_64`).

Для комплекта MSVC — из «x64 Native Tools Command Prompt for VS 2022», для MinGW
подойдёт обычный `cmd`:

```bat
cd <путь к репозиторию>
cmake -S . -B build -DCMAKE_PREFIX_PATH="<папка Qt-комплекта>"
cmake --build build --config Release
```

Ошибка `Could not find a package configuration file for "Qt6"` означает, что в
`CMAKE_PREFIX_PATH` указана не та папка (нужна та, где есть `lib\cmake\Qt6`).

### 2.4. Разложить Qt-DLL (чтобы `.exe` запускался двойным щелчком)

Из Qt Creator клиент работает и без этого шага. Для самостоятельного запуска
библиотеки раскладывает `windeployqt.exe` — он лежит в том же `bin`, что и
`qmake.exe`:

```bat
"<папка Qt-комплекта>\bin\windeployqt.exe" --release build\bin\akinator-client.exe
```

`gamecore.dll` уже лежит в `build\bin` (единая папка вывода), поэтому `.exe`
нельзя переносить поодиночке — только вместе с папкой `bin`.

### 2.5. Подключиться к серверу

1. Запустить клиент (`build\bin\akinator-client.exe` или `Ctrl+R` в Qt Creator).
2. В поле **«Адрес сервера»** ввести адрес из шага **1.4**, например
   `10.126.245.249`; **«Порт»** — `9999`; нажать **«Подключиться»**.
3. Второй игрок — это **второй запуск того же `.exe`** (один клиент = один игрок).
4. Проверка связи до игры, в PowerShell:

```powershell
Test-NetConnection 10.126.245.249 -Port 9999   # нужно TcpTestSucceeded : True
```

`127.0.0.1` — это **сам клиентский компьютер**: если сервер на другой машине,
такой адрес даст `Connection refused` (клиент покажет подсказку с испробованным
адресом). Переменные окружения нужны только для предзаполнения полей и не
переопределяют введённое в окне: `GAME_SERVER_HOST` и `GAME_SERVER_PORT`.


## Часть 3. Как играть

1. Оба клиента нажали «Подключиться» — сервер прислал `welcome` и номер игрока
   (игрок 1 / игрок 2). Порядок хостов не важен.
2. Каждый выбирает персонажа из 60 (в списке есть поиск) и жмёт «Загадать
   выбранного». После этого список блокируется: сменить секрет нельзя.
3. Когда загадали оба, приходит `start` — первым ходит игрок 1, далее по очереди.
4. В свой ход доступно:
   - **«Задать вопрос»** — 139 вопросов с поиском (уже заданные скрыты), ответ
     `да`/`нет` вычисляет сервер по таблице секрета;
   - **«Открыть таблицу»** — кандидаты соперника; обычный вопрос таблицу **не**
     сокращает, лишних убирают вручную кнопкой «Удалить выбранных»;
   - **3 подсказки** (по одной на партию): дисперсия, Random Forest,
     CatBoost-подобный бустинг — подсказка сама выбирает вопрос и сразу
     отфильтровывает неподходящих;
   - **«Угадать»** — выбор из текущих кандидатов.
5. Верная догадка → `matchover` обоим, экран победы с именем персонажа; неверная →
   ход переходит сопернику.
6. После партии — «Реванш» (нужно согласие обоих) или «Выход».
7. Закрыли клиент — второй видит «Противник отключился», лобби снова свободно.
8. Третьего игрока сервер не пустит: `error` «Сервер занят» и отключение.

## Часть 4. Если не подключается

| Симптом | Причина и решение |
|---|---|
| `Connection refused` по введённому адресу | сервер не запущен, слушает другой порт или в поле не тот адрес. Сверьте адрес с шагом 1.4 и порт `9999` |
| `Connection refused` при верном IP | порт закрыт фаерволом на сервере (шаг 1.6) |
| Тайм-аут вместо отказа | машины не видят друг друга: на обеих должен быть статус `OK` в `zerotier-cli listnetworks`, участники авторизованы на my.zerotier.com |
| Играю через ZeroTier, а connection refused | в поле нужен ZT-адрес **сервера** (`10.x.x.x` из шага 1.4), а не свой адрес и не `127.0.0.1` |
| «Сервер занят» | лобби строго на 2 игрока: закройте лишний клиент (в том числе запущенный ранее на сервере) |
| «Не найден Qt6Widgets.dll» | не выполнен шаг 2.4 (`windeployqt`) |
| «Не найден gamecore.dll» | `.exe` вынесен из `build\bin` — вернуть его или скопировать DLL рядом |
| Кракозябры в логе сервера/клиента на Windows | `chcp 65001` в `cmd` перед запуском |

## Справка

**Переменные окружения** (у клиента приоритет у полей окна):

| Переменная | Где | Смысл | По умолчанию |
|---|---|---|---|
| `GAME_SERVER_PORT` | сервер | порт прослушивания | `9999` |
| `GAME_SERVER_HOST` | клиент | предзаполняет «Адрес сервера» | `127.0.0.1` |
| `GAME_SERVER_PORT` | клиент | предзаполняет «Порт» | `9999` |

Некорректные значения (не число, порт вне `1..65535`) заменяются на дефолт с
предупреждением в stderr (сервер) или в статусной строке (клиент).

**Тесты** — `ctest --test-dir build --output-on-failure`:

- `tst_gamecore` (14 тестов) — целостность данных 60×139, `value`,
  `filterCandidates` (да/нет/пусто/порядок), три подсказки (валидность,
  детерминизм, отсутствие информации);
- `tst_protocol` (14 тестов) — разбор всех клиентских сообщений, сериализация
  серверных, невалидный ввод, кадрирование нескольких сообщений в одном буфере,
  round-trip всех 20 типов, `remaining`/`count` до 60.

**Модули:**

| Модуль | Тип | Содержимое |
|---|---|---|
| `gamecore` | SHARED (`libgamecore.so` / `gamecore.dll`) | данные 60×139, `value`, `filterCandidates`, `hintVariance`/`hintRandomForest`/`hintCatBoost` |
| `akinator_protocol` | STATIC (`libakinator_protocol.a`) | NDJSON-протокол: разбор и сборка 20 типов сообщений |
| `akinator-server` | exe | `QTcpServer`, лобби на 2 игрока, авторитетные ответы, подсказки, реванш |
| `akinator-client` | exe | Qt Widgets GUI: подключение, выбор секрета, игровой экран, тема |
| `tests` | exe × 2 | `tst_gamecore`, `tst_protocol` |

**Данные** уже закоммичены (`gamecore/generated/data.{h,cpp}`). Пересобрать из
`data/selected_characters.csv`: `python3 tools/generate_data.py` (Python нужен
только для этого, в рантайме не требуется; `1` — «да», `-1` — «нет»).

**Оформление** — тёмная фиолетово-золотая тема `client/style.qss` и иллюстрации
состояний (`idle`/`think`/`happy`/`hard`) из `client/assets/`, вшиты в бинарник
через `client/resources.qrc` (AUTORCC), поэтому рядом с `.exe` файлов не нужно.
Чтобы заменить картинки, положите новые PNG с теми же именами и пересоберите.

**Протокол** — TCP, NDJSON (один JSON-объект в строке, UTF-8). Полное описание
20 типов сообщений и конечных автоматов — в `AKINATOR_BATTLE_TZ.md`, раздел 6.


## Демо-чек-лист

1. `cmake -S . -B build && cmake --build build` — собирается на Linux и Windows.
2. `ctest --test-dir build --output-on-failure` — все тесты зелёные.
3. `gamecore` — SHARED-библиотека, реально используемая сервером, клиентом и тестами.
4. `python3 tools/generate_data.py` — данные пересобираются из CSV детерминированно.
5. `GAME_SERVER_PORT=9999 ./build/bin/akinator-server` — в логе `Сервер слушает 0.0.0.0:9999`.
6. Два клиента на один адрес → выбор персонажей → `start`.
7. Обычный вопрос → `answer`, таблица не изменилась; «Открыть таблицу» + «Удалить
   выбранных» → `remove_ok` с новым `remaining`.
8. Три подсказки → лучший вопрос и автофильтрация; «Угадать» → `matchover`.
9. Env: без переменных — дефолты, с `GAME_SERVER_HOST`/`GAME_SERVER_PORT` — заданный адрес.
10. Закрыть клиент → «Противник отключился»; третий клиент → `error` «Сервер занят».
